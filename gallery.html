One little setup step

Create a Supabase project and invite both email accounts in Authentication → Users. Replace the two email placeholders in supabase-setup.sql, then run or re-run the latest version in SQL Editor to enable profiles, private daily notes and reactions, and shared design settings. Confirm it reports one owner and one member. Keep that SQL file out of GitHub. Set the project URL in supabase-config.js and serve the site over HTTPS.
